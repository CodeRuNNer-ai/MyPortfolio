# Abhijeet Bhandari — 3D Character Portfolio

An award-winning caliber interactive 3D character portfolio website inspired by the iconic clay/risograph 3D character aesthetic with playful face stickers, real-time 3D cursor eye-tracking, and mouse-scroll guided cinematic face gliding.

---

## 🌟 Highlights & Key Features

1. **Clay 3D Character Rig**
   - Sculpted stylized character matching the reference image.
   - Clay hair locks with natural volume and tapered bangs framing the forehead.
   - Signature comedic/nervous wide grimace smile displaying upper and lower cartoon teeth rows.
   - Warm peach skin tone with blushing cheeks, nose tip blush, and freckles.

2. **Real-Time Eyeball & Head Cursor Tracking**
   - The character's 3D eyeballs track the user's cursor / pointer anywhere across the screen.
   - Dynamic 3D look-at projection with natural anatomical angle clamping.
   - Secondary head inertia: head swivels organically with spring damping and natural lag.
   - Realistic micro-blinking eyelids and winking reactions.

3. **Scroll-Driven 3D Face Angle Gliding**
   - Scrolling glides the 3D camera smoothly around the character's face:
     - **Hero Section**: Frontal chest-up portrait (matching the reference photo).
     - **Story & Academic Journey**: Glides to a 3/4 right profile, zooming closer to face stickers.
     - **Tech Stack & Capabilities**: Dynamic low angle looking upwards with dramatic rim lighting.
     - **Featured Projects**: Glides to 3/4 left angle.
     - **Get In Touch**: Returns to front view with warm eye contact and friendly presence.

4. **Interactive Face Stickers**
   - Exact stickers from reference:
     - `ZOOOP!` comic bubble across nose bridge
     - `I ❤️ SYS` on cheek
     - Kawaii Bear / Onigiri sticker
     - Yellow bandage / plaster on forehead
     - `React` & `Java` tech badges
     - Thumbs Up badge
   - Hovering or clicking stickers triggers a 3D bounce, sound effect, and interactive info tooltip.

5. **Aesthetic & Print Design**
   - Sage-green background (`#879981`) matching the reference photo.
   - Vintage diagonal halftone risograph overlay with toggle.
   - Subtle paper grain noise filter.
   - Chalk / brush handwritten headline: *"About Abhijeet"*.
   - Minimalist *"SCROLL"* vertical guide line.

6. **Web Audio API Sound Effects**
   - Pure procedural synthesized UI audio (no external sound files required).
   - Pops, clicks, winks, and chord feedback for button interactions.

## 🚀 How to Run

### Option 1: Double-Click Batch File (Recommended)
Double-click `start-portfolio.bat` in this folder. It will automatically start a local server using Java's built-in `jwebserver` on `http://localhost:3000` and open it in your browser.

### Option 2: Direct Browser Open
Double-click or open `index.html` directly in Google Chrome, Microsoft Edge, Opera GX, or Brave. All scripts and textures run locally with zero build steps or server requirements!
